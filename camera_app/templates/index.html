Ground receiver command


      
Run this command from the project directory on Ubuntu. It opens a native H.264 viewer. The browser preview above uses MJPEG.

      
One encoder supplies RTP and recording. Stop both before changing capture format or encoder bitrate. RTP is not automatically resumed after a Pi restart.

      
RTP/UDP is unencrypted. Use a trusted LAN or an encrypted radio/tunnel. Packet counters indicate local sends, not confirmed ground reception.
